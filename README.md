# Growbox PIPAS

Прошивка автоматизированной системы управления гроубоксом (закрытым
растениеводческим боксом) на базе Arduino Uno. Система поддерживает заданные
условия окружающей среды, управляя освещением, поливом, проветриванием
и увлажнением по показаниям датчиков и расписаниям, а также принимает команды
управления по Bluetooth.

- **Название прошивки:** Growbox PIPAS
- **Версия прошивки:** 1.0.0
- **Платформа:** Arduino Uno (ATmega328P, 16 МГц)
- **Сборка:** PlatformIO (framework Arduino)

## Возможности

- **Лампа** — освещение по заданному периоду активности (в течение суток);
- **Насос** — автоматический полив по влажности почвы с гистерезисом,
  ограничениями максимального времени работы, паузы между запусками
  и максимальной частоты полива;
- **Вентилятор** — проветривание по температуре и влажности воздуха
  с гистерезисом;
- **Увлажнитель воздуха** — поддержание влажности воздуха с гистерезисом;
- **Часы реального времени** — точное время и расписания (RTC RX-8025T);
- **Хранение настроек** в EEPROM AT24C256 со wear leveling (равномерный
  износ памяти, циклическая запись);
- **Управление по Bluetooth** (HC-05) с мобильного устройства: чтение
  показаний, изменение всех настроек, ручное управление механизмами,
  установка времени, калибровочный режим;
- **Кнопка** принудительного включения Bluetooth;
- **Автоматическое отключение Bluetooth** при отсутствии соединения
  (энергосбережение);
- **Ручной и автоматический режимы** для каждого исполнительного механизма,
  калибровочный режим работы устройства.

## Аппаратная часть

| Модуль | Назначение |
| :--- | :--- |
| Arduino Uno R3 | Контроллер |
| RTC RX-8025T (Trema) | Часы реального времени (I²C) |
| EEPROM AT24C256 | Хранение конфигурации (I²C, адрес 0x50) |
| DHT22 (модуль Waveshare) | Температура и влажность воздуха |
| Датчики влажности почвы (1–2 шт.) | Контроль влажности почвы (АЦП) |
| Релейные модули 5 В / 30 А (опторазвязка) | Лампа, вентилятор, увлажнитель (220 В) |
| Силовые ключи N-канал (Trema) | Насос, питание HC-05 |
| Мембранный насос R385 (12 В) | Полив |
| HC-05 | Bluetooth-связь со смартфоном |
| Блок питания 12 В / 2 А + DC-DC LM2596 (5 В) | Питание системы |

Подробные перечень оборудования, схемы питания и подключения — в документе
по сборке (см. ниже).

## Сборка и прошивка

```bash
# клонирование репозитория
git clone git@github.com:conner80/growbox_fw.git
cd growbox_fw

# сборка
pio run

# загрузка в плату (Arduino Uno подключена по USB)
pio run --target upload
```

Зависимости (`platformio.ini`):

- `tremaru/iarduino_RTC@^2.0.9` — работа с RTC;
- `tremaru/iarduino_DHT@^1.1.3` — работа с датчиками DHT11/DHT22.

Аппаратная конфигурация (пины, типы реле и ключей, тайминги) задаётся
макросами в `lib/hal/hal.h`; пользовательские настройки по умолчанию —
в `include/config/config.h`.
