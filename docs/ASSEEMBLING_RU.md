# Сборка устройства Growbox PIPAS

Документ описывает оборудование, используемое для сборки контроллера гроубокса,
и приводит схему подключения всех модулей к Arduino Uno R3.

Назначение выводов, приведённое в схеме, соответствует конфигурации прошивки
в файле `lib/hal/hal.h`. Если пины изменены в конфигурации, схему нужно
скорректировать аналогично.

---

[market.yandex.ru](https://market.yandex.ru/cc/Bdqi7W)

Двухканальный модуль электромеханических реле (тип реле SLA-05VDC-SL-C)

## 3. Схема распределения питания

```
                 Блок питания 12 В / 2 А
                 (DC jack 5,5×2,1, центр «+»)
                          │
        ┌─────────────────┼───────────────────────────┐
        │                                             │
   ┌────┴─────┐                              ┌─────────┴────────┐
   │ Насос    │                              │ DC-DC            │
   │ R385     │                              │ LM2596           │
   │ (+) = 12 В│                             │ IN+ / IN−        │
   └────┬─────┘                              │ OUT+ / OUT− = 5 В│
        │                                    └─────────┬────────┘
   (−) насоса                                          │
   через силовой                                 ═══════╧═══════ ШИНА +5 В
   ключ (D4)                                      │ │ │ │ │ │ │ │
   + диод 1N4007                             ┌───┴─┴─┴─┴─┴─┴─┴───┐
   (см. ниже)                                │ к Arduino (контакты
                                             │ USB-B: VBUS и GND,
                                             │ прямая подпайка),
                                             │ релейным модулям (VCC),
                                             │ HC-05 (через ключ D6),
                                             │ RTC, EEPROM, DHT, ключам
                                             │ SIG-VCC, датчикам почвы
                                             └────────────────────┘

   ═════╧═════ ОБЩИЙ ПРОВОД GND (все модули, минус БП, минус DC-DC)
```

Примечания по питанию:

- **Никаких «земельных» развязок между цепями 12 В и 5 В нет** — GND всех
  устройств обязан быть соединён;
- **Насос — единственная нагрузка, питающаяся от шины 12 В напрямую**;
  его минус коммутируется силовым ключом;
- **Arduino и все модули питаются от шины 5 В**, которую формирует DC-DC
  из 12 В. Выход DC-DC подпаивается к контактам разъёма USB-B на плате
  Arduino (VBUS и GND) — см. схему ниже; штатный DC-разъём и вывод Vin
  не используются;
- Напряжение DC-DC должно быть выставлено ровно 5,0 В **до** подпайки:
  контакты USB-B соединены с питанием микроконтроллера напрямую, минус
  защитных диодов и стабилизатора;
- Релейные модули питаются от шины 5 В; их опторазвязанные входы IN
  управляются выводами 5 В Arduino.

### Подпайка DC-DC к плате Arduino (питание через USB-B)

Плата Arduino запитывается от шины 5 В напрямую: провода OUT+ и OUT−
DC-DC преобразователя подпаиваются к контактам разъёма **USB-B** на плате
со стороны пайки:

```
        DC-DC OUT+ (5 В) ──────► контакт 1 (VBUS) разъёма USB-B
        DC-DC OUT− (GND) ──────► контакт 4 (GND) разъёма USB-B
```

Разъём USB-B (вид на пины разъёма со стороны установки):

```
        ┌─── оболочка разъёма ───┐
        │  ┌────┬────┬────┬────┐ │
        │  │ 1  │ 2  │ 3  │ 4  │ │
        │  │VBUS│ D− │ D+ │GND │ │
        └──┴────┴────┴────┴────┘─┘
            ▲              ▲
            │              │
      подпаять        подпаять
      OUT+ (5 В)      OUT− (GND)
```

- Контакты 2 (D−) и 3 (D+) — линии данных USB, их не задействуем;
- Контакт 1 (VBUS) — плюс питания 5 В;
- Контакт 4 (GND) — общий провод;
- при подключении платы к ПК по USB для прошивки внешнее питание от DC-DC
  желательно отключать (два источника 5 В не должны работать на одну шину).

В качестве альтернативы допустимо подпаивать OUT+/OUT− к площадкам выводов
**5V** и **GND** платы (колодка питания) — схемотехнически это тот же узел
питания, что и VBUS USB-B.

## 4. Схема подключения сигналов

```
                        Arduino Uno R3
                    ┌────────────────────┐
  Почва 1 (OUT) ────┤A0                  │
  Почва 2 (OUT) ────┤A1                  │
  I²C SDA ──────●───┤A4                  │  ●── к SDA RTC и SDA EEPROM
  I²C SCL ──────●───┤A5                  │  ●── к SCL RTC и SCL EEPROM
  Реле увлажн. ─────┤D2                  │
  Реле вент.   ─────┤D3                  │
  Ключ насоса  ─────┤D4                  │
  Реле лампы   ─────┤D5                  │
  Ключ пит. BT ─────┤D6                  │
  Кнопка ───────────┤D7              D9├────◄── TX HC-05 (напрямую)
                    │                 D10├──[1к]──┬──► RX HC-05
  DHT (DATA) ───────┤D11               D12├────◄── STATE HC-05 (напрямую)
                    │                 D13├──[1к]──┬──► EN (KEY) HC-05
  Питание 5 В ◄─────┤5V                   │      │        │
  Общий GND ─────●──┤GND                  │    [2к]      [2к]
                    └────────────────────┘      │          │
                                               GND        GND
```

### Подключение HC-05 (согласование уровней 5 В → 3,3 В)

Входы **RX** и **EN (KEY)** модуля HC-05 не толерантны к 5 В, поэтому оба
управляющих сигнала от Arduino подключаются через делители напряжения
1 кОм / 2 кОм (на выходе делителя 5 В × 2/(1+2) ≈ 3,3 В):

```
D10 ──[1кОм]──┬────► RX HC-05                D13 ──[1кОм]──┬────► EN HC-05
              │                                             │
            [2кОм]                                        [2кОм]
              │                                             │
             GND                                           GND
```

Выходы модуля **TX** и **STATE** (3,3 В) подключаются к D9 и D12 напрямую —
для Arduino уровень 3,3 В гарантированно распознаётся как логическая единица.
Питание модуля (VCC 5 В, GND) коммутируется вторым силовым ключом
с вывода D6: `+5 В → клеммник ключа → ключ (управление D6) → VCC HC-05`.

### Подключение насоса (защита от ЭДС самоиндукции)

Насос — индуктивная нагрузка с коллекторным двигателем; при отключении
в обмотке возникает выброс ЭДС, способный вывести из строя силовой ключ.
Диод **1N4007** ставится **встречно-параллельно** двигателю (катодом к +12 В):

```
+12 В ────┬────────────► (+) насоса
          │
        ──┴── 1N4007 (анод вниз, катодом к +12 В)
          │
          └────────────► (−) насоса ──► силовой ключ (управление D4) ──► GND
```

В нормальном режиме диод закрыт; при выключении насоса ток самоиндукции
замыкается через диод, гася выброс.

### Подключение релейных модулей

Релейные каналы коммутируют сетевые нагрузки 220 В — лампу, вентилятор
и увлажнитель. У каждого канала: вход `IN` — к соответствующему выводу
Arduino (D2, D3, D5), `VCC` — к шине +5 В, `GND` — к общей земле. Нагрузка
подключается к винтовым клеммам контактной группы: **COM** — питающая сеть
(фаза 220 В), **NO** — нагрузка; контакт **NC** не используется.

⚠️ Внимание: контактные группы реле находятся под сетевым напряжением 220 В.
Силовую часть (реле, клеммники, провода сети) необходимо изолировать
(корпус, термоусадка, изолированные клеммники) и размещать отдельно
от слаботочной части.

**Примечание о типе триггера:** прошивка (`RELAY_TYPE` = 1) рассчитана на реле,
включаемое высоким уровнем (HIGH). Если конкретный модуль срабатывает
низким уровнем (LOW-level trigger), для этого канала в `lib/hal/hal.h`
следует указать тип 3 (p-channel key — инверсная логика).

### Подключение шины I²C (RTC и EEPROM)

Оба модуля сидят на одной шине: **SDA → A4**, **SCL → A5**, питание +5 В.
- RTC RX-8025T: 4 провода (VCC, GND, SDA, SCL), батарейка CR1220 — в слот;
- EEPROM AT24C256: VCC, GND, SDA, SCL; **A0–A2 → GND** (адрес 0x50,
  как задано в прошивке), **WP → GND** (запись разрешена).

Подтягивающие резисторы шины I²C (4,7 кОм к +5 В) обычно уже установлены
на модулях; при длинных соединениях проверьте наличие хотя бы одной пары.

### Подключение датчиков

- **DHT22 (модуль Waveshare):** VCC → +5 В, GND → GND, DATA → D11
  (подтягивающий резистор установлен на плате модуля);
- **Датчики влажности почвы:** VCC → +5 В, GND → GND, AO → A0 (датчик 1)
  и A1 (датчик 2);
- **Кнопка:** один контакт → D7, второй → GND.

---

## 5. Итоговая карта выводов

| Вывод Arduino | Устройство | Сигнал |
| :---: | :--- | :--- |
| A0 | Датчик почвы 1 | AO (аналоговый) |
| A1 | Датчик почвы 2 | AO (аналоговый) |
| A4 | RTC + EEPROM | I²C SDA |
| A5 | RTC + EEPROM | I²C SCL |
| D2 | Реле увлажнителя | IN (тип 1) |
| D3 | Реле вентилятора | IN (тип 1) |
| D4 | Силовой ключ насоса | SIG (тип 2) |
| D5 | Реле лампы | IN (тип 1) |
| D6 | Ключ питания HC-05 | SIG (тип 2) |
| D7 | Кнопка включения BT | к GND, INPUT_PULLUP |
| D9 | HC-05 | TX модуля → вход Arduino |
| D10 | HC-05 | RX модуля через делитель 1к/2к |
| D11 | Датчик DHT | DATA |
| D12 | HC-05 | STATE |
| D13 | HC-05 | EN (KEY) через делитель 1к/2к |
| 5V | Шина +5 В от DC-DC | питание модулей |
| GND | Общий | все модули и силовая часть |

Выводы D0/D1 (аппаратный UART) и D8 в проекте не заняты и остаются
для отладки и расширения.
