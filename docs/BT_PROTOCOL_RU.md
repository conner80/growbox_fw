# Протокол взаимодействия с устройством через BLUETOOTH

Описание протокола взаимодействия с устройством через Bluetooth.

## Общее описание протокола

Для взаимодействия с устройством используется двоичный протокол управления через сеть Bluetooth.
Формат протокола следующий:
```
<Begin packet><Command>[Command data length][Command data]
```

**ВНИМАНИЕ!** Для некоторых команд может не быть передаваемых и возврщаемых данных, в этом случае поля ***Command data length*** и ***Command data*** не передаеются. Если параметры подразумеваются, но они не обязательные - передается только параметр ***Command data length*** равный **0**. 

Где:
- **Begin packet** - Начало пакета (Всегда 0xFE - запрос, 0xEF - ответ).
- **Command** - [Команда](#доступные-команды) к устройству.
- **Command data length** - Длинна данных команды.
- **Command data** - Данные команды.

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x01 | Начало пакета (Всегда 0xFE - запрос, 0xEF - ответ) |
| 0x01 | 0x01 | [Команда](#доступные-команды) к устройству |
| 0x02 | 0x01 | Длинна данных команды |
| 0x03 | 0x01 - 0xFF | Данные команды |

## Доступные команды

Команды делятся на два типа:
1. **Запрос** - Запрос к устройству (***Begin packet == 0xFE***).
2. **Ответ** - Ответ от устройства с результатом (***Begin packet == 0xEF***).

Таким образом, обмен (выполнение одной команды) состоит из двух пакетов: запрос и ответ.

**ВНИМАНИЕ!** Описание команд будет содержать описание структур для ***Command data***, которая должна быть инкапсулирована в сам [пакет запроса/ответа](#общее-описание-протокола). При успешном принятии пакета, принимающая сторона должна отправить пакет ACK, в противном случае NACK

## Положительное подтверждение приема данных (ACK)

Данный пакет состоит из одного байта и отправляется при успешном принятии пакета.

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x01 | Сигнатура 0xAA |

## Отрицательное подтверждение приема данных (NACK)

Данный пакет состоит из одного байта и отправляется при неудачном принятии пакета (битые данные).

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x01 | Сигнатура 0xBB |

### Получение общей информации

Команда возвращает общую информацию об устройстве (версию прошивки, набор устройств, датчиков и т.д.).

**Команда: 0x01**

**__Запрос:__**

None

**__Ответ:__**

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x15 | Наименование устройства (20 символов) |
| 0x015 | 0x0B | Версия прошивки устройства (10 символов) |
| 0x20 | 0x15 | Версия прошивки Bluetooth (20 символов) |
| 0x35 | 0x02 | [Маска](#формат-маски-устройств) активных датчиков и исполнительных механизмов устройства |
| 0x37 | 0x01 | Режим работы устройства: <br><b>0x00</b> - Калибровка<br><b>0x01</b> - Стандартный режим работы | 

**ВНИМАНИЕ!** [Маска устройств](#формат-маски-устройств) используется, как для обращения к устройству (получение его показаний/статуса), так и для управления исполнительными механизмами (насос, лампа и т.д.).


#### Формат маски устройств

| Бит | Значение | Описание |
| :---: | :---: | :--- |
| 0 | 0x0001 | Часы реального времени |
| 1 | 0x0002 | Память для хранения настроек |
| 2 | 0x0004 | Дачик влажности и температуры воздуха |
| 3 | 0x0008 | Датчик влажности почвы 1 |
| 4 | 0x0010 | Датчик влажности почвы 2 |
| 5 | 0x0020 | Датчик углекислого газа |
| 8 | 0x0100 | Реле/Ключ управления лампой |
| 9 | 0x0200 | Реле/Ключ управления вентилятором |
| 10 | 0x0400 | Реле/Ключ управления насосом |
| 11 | 0x0800 | Реле/Ключ управления увлажнителем воздуха |

### Получить имя устройства и адрес устройства

Возвращает имя и адрес Bluetooth устройства, по которому его можно найти.

**Команда: 0x02**

**__Запрос:__**

None

**__Ответ:__**

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x21 | Наименование устройства (32 символа) |
| 0x21 | 0x0F | Адрес устройства (NAP:UAP:LAP) |

### Получить состояние устройства

Возвращает текущее состояние датчиков и/или исполнительных механизмов.

**Команда: 0x07**

**__Запрос:__**

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x02 | [Маска оборудования](#формат-маски-устройств) |

**__Ответ:__**

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x01 | Код ответа: <br><b>0x00</b> - Успех<br><b>0x01</b> - Ошибка формата<br><b>0x02</b> - Устройство не активно/не доступно |
| 0x01 | 0x02 | Устройство 1 (значение бит для одного устройства) |
| 0x02 | dyn | Данные устройства |

**ВНИМАНИЕ!** Если код ответа не ***0x00*** - данные об устройств(е, ах) отсутствуют. Все параметры устройств передаются последовательно, согласно маске оборудования из запроса.

### Изменить состояние устройства

**__Запрос:__**

| Смещение | Размер байт | Описание |
| :---: | :---: | :--- |
| 0x00 | 0x01 | Сохранять изменения в EEPROM или нет (```uint8```) |
