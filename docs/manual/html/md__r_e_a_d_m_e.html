Growbox PIPAS

Прошивка автоматизированной системы управления гроубоксом (закрытым растениеводческим боксом) на базе Arduino Uno. Система поддерживает заданные условия окружающей среды, управляя освещением, поливом, проветриванием и увлажнением по показаниям датчиков и расписаниям, а также принимает команды управления по Bluetooth.

  • Название прошивки: Growbox PIPAS
  • Версия прошивки: 1.0.0
  • Платформа: Arduino Uno (ATmega328P, 16 МГц)
  • Сборка: PlatformIO (framework Arduino)

Возможности

  • Лампа — освещение по заданному периоду активности (в течение суток);
  • Насос — автоматический полив по влажности почвы с гистерезисом, ограничениями максимального времени работы, паузы между запусками и максимальной частоты полива;
  • Вентилятор — проветривание по температуре и влажности воздуха с гистерезисом;
  • Увлажнитель воздуха — поддержание влажности воздуха с гистерезисом;
  • Часы реального времени — точное время и расписания (RTC RX-8025T);
  • Хранение настроек в EEPROM AT24C256 со wear leveling (равномерный износ памяти, циклическая запись);
  • Управление по Bluetooth (HC-05) с мобильного устройства: чтение показаний, изменение всех настроек, ручное управление механизмами, установка времени, калибровочный режим;
  • Кнопка принудительного включения Bluetooth;
  • Автоматическое отключение Bluetooth при отсутствии соединения (энергосбережение);
  • Ручной и автоматический режимы для каждого исполнительного механизма, калибровочный режим работы устройства.

Мембранный насос R385 (12 В) Полив
HC-05 Bluetooth-связь со смартфоном
Блок питания 12 В / 2 А + DC-DC LM2596 (5 В) Питание системы

Документация

  • docs/OVERVIEW_RU.md — подробное описание работы проекта: архитектура, жизненный цикл, алгоритмы управления, конфигурация, хранение в EEPROM, Bluetooth-протокол на уровне обработки команд;
  • docs/ASSEMBLING_RU.md — перечень оборудования со ссылками, схема распределения питания, схема подключения всех модулей к Arduino (включая согласование уровней HC-05 и защиту от ЭДС насоса);
  • docs/BT_PROTOCOL_RU.md — формат пакетов двоичного протокола Bluetooth, описание команд и структур данных.

Сборка и прошивка

# сборка
pio run
# загрузка в плату (Arduino Uno подключена по USB)
pio run --target upload

Зависимости (platformio.ini):

  • tremaru/iarduino_RTC@^2.0.9 — работа с RTC;
  • tremaru/iarduino_DHT@^1.1.3 — работа с датчиками DHT11/DHT22.

Аппаратная конфигурация (пины, типы реле и ключей, тайминги) задаётся макросами в lib/hal/hal.h; пользовательские настройки по умолчанию — в include/config/config.h.
