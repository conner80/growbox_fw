Прошивка автоматизированной системы управления гроубоксом (закрытым растениеводческим боксом) на базе Arduino Uno. Система поддерживает заданные условия окружающей среды, управляя освещением, поливом, проветриванием и увлажнением по показаниям датчиков и расписаниям, а также принимает команды управления по \doxylink{class_bluetooth}{Bluetooth}.


\begin{DoxyItemize}
\item {\bfseries{Название прошивки:}} Growbox PIPAS
\item {\bfseries{Версия прошивки:}} 1.\+0.\+0
\item {\bfseries{Платформа:}} Arduino Uno (ATmega328P, 16 МГц)
\item {\bfseries{Сборка:}} Platform\+IO (framework Arduino)
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md98}{}\doxysection{\texorpdfstring{Возможности}{Возможности}}\label{md__r_e_a_d_m_e_autotoc_md98}

\begin{DoxyItemize}
\item {\bfseries{Лампа}} — освещение по заданному периоду активности (в течение суток);
\item {\bfseries{Насос}} — автоматический полив по влажности почвы с гистерезисом, ограничениями максимального времени работы, паузы между запусками и максимальной частоты полива;
\item {\bfseries{Вентилятор}} — проветривание по температуре и влажности воздуха с гистерезисом;
\item {\bfseries{Увлажнитель воздуха}} — поддержание влажности воздуха с гистерезисом;
\item {\bfseries{Часы реального времени}} — точное время и расписания (\doxylink{class_r_t_c}{RTC} RX-\/8025T);
\item {\bfseries{Хранение настроек}} в EEPROM AT24\+C256 со wear leveling (равномерный износ памяти, циклическая запись);
\item {\bfseries{Управление по \doxylink{class_bluetooth}{Bluetooth}}} (HC-\/05) с мобильного устройства: чтение показаний, изменение всех настроек, ручное управление механизмами, установка времени, калибровочный режим;
\item {\bfseries{Кнопка}} принудительного включения \doxylink{class_bluetooth}{Bluetooth};
\item {\bfseries{Автоматическое отключение \doxylink{class_bluetooth}{Bluetooth}}} при отсутствии соединения (энергосбережение);
\item {\bfseries{Ручной и автоматический режимы}} для каждого исполнительного механизма, калибровочный режим работы устройства.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md99}{}\doxysection{\texorpdfstring{Аппаратная часть}{Аппаратная часть}}\label{md__r_e_a_d_m_e_autotoc_md99}
