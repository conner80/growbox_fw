Описание протокола взаимодействия с устройством через \doxylink{class_bluetooth}{Bluetooth}.\hypertarget{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md29}{}\doxysection{\texorpdfstring{Общее описание протокола}{Общее описание протокола}}\label{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md29}
Для взаимодействия с устройством используется двоичный протокол управления через сеть \doxylink{class_bluetooth}{Bluetooth}. Формат протокола следующий: 
\begin{DoxyCode}{0}
\DoxyCodeLine{<Begin\ packet><Command>[Command\ data\ length][Command\ data]}

\end{DoxyCode}


{\bfseries{ВНИМАНИЕ!}} Для некоторых команд может не быть передаваемых и возврщаемых данных, в этом случае поля {\itshape {\bfseries{Command data length}}} и {\itshape {\bfseries{Command data}}} не передаеются. Если параметры подразумеваются, но они не обязательные -\/ передается только параметр {\itshape {\bfseries{Command data length}}} равный {\bfseries{0}}.

Где:
\begin{DoxyItemize}
\item {\bfseries{Begin packet}} -\/ Начало пакета (Всегда 0x\+FE -\/ запрос, 0x\+EF -\/ ответ).
\item {\bfseries{Command}} -\/ Команда к устройству.
\item {\bfseries{Command data length}} -\/ Длинна данных команды.
\item {\bfseries{Command data}} -\/ Данные команды.
\end{DoxyItemize}

\hypertarget{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md30}{}\doxysection{\texorpdfstring{Доступные команды}{Доступные команды}}\label{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md30}
Команды делятся на два типа:
\begin{DoxyEnumerate}
\item {\bfseries{Запрос}} -\/ Запрос к устройству ({\itshape {\bfseries{Begin packet == 0x\+FE}}}).
\item {\bfseries{Ответ}} -\/ Ответ от устройства с результатом ({\itshape {\bfseries{Begin packet == 0x\+EF}}}).
\end{DoxyEnumerate}

Таким образом, обмен (выполнение одной команды) состоит из двух пакетов: запрос и ответ.

{\bfseries{ВНИМАНИЕ!}} Описание команд будет содержать описание структур для {\itshape {\bfseries{Command data}}}, которая должна быть инкапсулирована в сам пакет запроса/\+ответа. При успешном принятии пакета, принимающая сторона должна отправить пакет ACK, в противном случае NACK\hypertarget{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md31}{}\doxysection{\texorpdfstring{Положительное подтверждение приема данных (ACK)}{Положительное подтверждение приема данных (ACK)}}\label{md_docs_2_b_t___p_r_o_t_o_c_o_l___r_u_autotoc_md31}
Данный пакет состоит из одного байта и отправляется при успешном принятии пакета.
